speciesot
=========
Geometric inference of cross-species transcriptome correspondence using Gromov–Wasserstein optimal transport.

.. image:: https://raw.githubusercontent.com/yuyatokuta/Species-OT/main/docs/_static/fig.png
   :alt: Overview figure
   :align: center
   :width: 600px


Installation
------------
.. code-block::

   pip install speciesot


Requirements
------------
- Python 3.12.7
- NVIDIA GPUs or Apple Silicon

Click `here <https://developer.apple.com/metal/jax/>`__ to learn how to utilize Apple Silicon's GPUs (official documentation).
